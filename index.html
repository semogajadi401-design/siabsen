Riwayat Absensi

Hapus data absensi (+ data sakit/izin, dan riwayat sesi piket bila reset semua kelas) berdasarkan kelas atau semua kelas sekaligus.

👨‍🎓

Data Siswa

Hapus semua data siswa (beserta riwayat absensi dan data sakit/izinnya).

👨‍🏫

Data Guru

Hapus semua data guru, jadwal piket, riwayat sesi piket, jadwal mengajar, dan riwayat absensi mengajar (kecuali akun admin).

📚

Jadwal Mengajar

Hapus semua jadwal mengajar, jam pelajaran, riwayat absensi mengajar guru, riwayat verifikasi kehadiran siswa per mapel, dan keterangan izin/sakit mengajar.

🗓️

Semester / Periode Akademik

Hapus semua data semester. Absensi tidak bisa dilakukan sampai semester baru dibuat & diaktifkan.

⚙️

Pengaturan Aplikasi

Kembalikan jam operasional, hari sekolah aktif, dan kalender hari libur ke pengaturan default. Profil sekolah tidak berubah.

☢️

Reset Total (Semua Data)

Menjalankan SEMUA kartu reset di atas sekaligus secara berurutan: absensi, siswa, guru, jadwal mengajar, semester, dan pengaturan aplikasi. Akun admin tetap aman.
